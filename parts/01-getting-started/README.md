# Part I - Getting started

[Book contents](../../index.md) | [Cover](../../README.md)

**Chapters 1-6**

Begin with the analytical question, then learn the platform's names and ownership boundaries. Build the same small retail model in a Warehouse and a Lakehouse before comparing their roles.

## Before you begin

No previous Fabric experience is assumed. Basic familiarity with tables and SELECT statements helps; the practical chapters identify the account, capacity and permissions they require.

Explain Fabric and OneLake, identify the writer for each item, reconcile the two independent examples, and describe where GPU acceleration can help without changing those responsibilities.
